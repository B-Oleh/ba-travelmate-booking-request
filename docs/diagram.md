# Feature: Пошук та фільтрація готелів
## Use Case: Search and filter hotels

Основні учасники — користувач і система TravelMate. Користувач може бути зареєстрованим або незареєстрованим: він вибирає місто й дати, шукає готелі, застосовує фільтри та вибирає готель зі списку. Діаграма також показує, що відбувається, якщо міста не існує або за вибраними параметрами немає результатів.

```mermaid
flowchart TD
    A(["Початок: користувач на головній сторінці"]) --> B["Користувач вводить або вибирає місто"]
    B --> C{"Місто існує?"}
    C -->|Ні| D["Система повідомляє: місто не існує, змініть запит"]
    D --> B
    C -->|Так| E["Система пропонує вибрати дати"]
    E --> F["Користувач вибирає дати"]
    F --> G["Користувач натискає Search"]
    G --> H{"Є доступні готелі?"}
    H -->|Ні| N["Система повідомляє: немає результатів, змініть параметри"]
    H -->|Так| I["Система показує доступні готелі"]
    I --> J["Користувач застосовує один або кілька фільтрів"]
    J --> K["Система оновлює список готелів"]
    K --> L{"Після фільтрації є результати?"}
    L -->|Так| M["Користувач вибирає готель зі списку"]
    M --> P["Система показує обраний готель"]
    P --> Q(["Кінець"])
    L -->|Ні| O["Система повідомляє: немає результатів, змініть фільтри"]
    O --> J
    N --> R["Користувач змінює параметри пошуку"]
    R --> B
```
